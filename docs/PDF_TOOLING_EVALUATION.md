RAG 三组对比：

- A（原始文本 + 固定分块）：Recall@5/10 20%，MRR 0.2615。
- B（清洗文本 + 结构分块）：Recall@5/10 90%，MRR 0.9077。
- C（parent/child + 表格上下文）：Recall@5/10 100%，MRR 1.0000；相对 B 再提升 10 个百分点。

清洗 P95 从 0.08 ms/样本增至 1.83 ms/样本，这是保留结构与生成审计轨迹的本地 CPU 开销；不包含 PDF 渲染、OCR、向量嵌入、数据库和网络时间，因此不能外推为生产延迟。

## 限制与上线验收

正式上线前还需要用户提供脱敏真实 PDF 和标注问答集，至少覆盖扫描质量、双栏、旋转、处方/检验表、跨页表、中文医学符号及错误 OCR。建议每类不少于 50 页，并报告 bootstrap 置信区间。若要评估回答模型本身，还需固定模型版本、提示词、温度、检索库快照和人工临床评分标准；本报告没有把确定性流水线分数冒充模型临床能力。

## 受控多 Agent 离线结果

同一次代码版本还执行了 `run_agent_evals.py`，报告为
`medagent-backend/evals/reports/agent_after_pdf_tooling_latest.json`：分诊意图、风险、急症召回、检索路由、术语保留、证据充分性、无效证据拒绝、引用正确/完整、输出安全和端到端任务成功率在随仓库附带的小规模合成集上均为 100%。其中分诊 4 条、规划 2 条、证据 2 条、答案 2 条、安全 3 条、端到端 3 条。

这些数值说明确定性回归用例全部通过，不足以证明真实临床问答达到 100%。仓库没有改造前同条件、同模型、同数据的真实 A 组运行记录，因此不能诚实计算“回答模型对比基线提升”。项目的 A/B/C/D 比较器会主动拒绝合成或缺失变体的数据；需要在具备在线模型凭据和脱敏真实集后采集四组执行记录。
